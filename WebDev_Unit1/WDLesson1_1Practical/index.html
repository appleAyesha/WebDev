Web Technologies

HTML

HTML, which stands for Hypertext Markup Language, is the standard coding language used to create the structure and layout of web pages. Think of it as the skeleton or structural backbone of every website on the internet. It tells your web browser (like Chrome or Safari) exactly how to display text, images, and links so you can interact with them.

CSS

CSS stands for Cascading Style Sheets. It is a style sheet language used to define the visual presentation, layout, and design of a website. Along with HTML (structure) and JavaScript (behavior), CSS is a cornerstone technology of the World Wide Web.

JavaScript

JavaScript (JS) is a lightweight, interpreted programming language used primarily to create dynamic and interactive content on the web. Alongside HTML and CSS, it serves as one of the three core foundational technologies powering the internet.
